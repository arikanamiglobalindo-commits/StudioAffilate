# StudioAffilate

Aplikasi desktop affiliate TikTok Shop (Python + Streamlit + n8n lokal).

| Modul | Isi |
|---|---|
| [`m1_riset/`](m1_riset/) | M1 Riset Produk: Kalodata Open API, 6 filter, skor, berburu footage seller, Gerbang Keputusan, antrean n8n, otomatisasi Senin & Kamis |
| [`web_analisa/`](web_analisa/) | Dashboard web analisa produk (Next.js): pencarian + filter, skor potensi, tren 7/30/90 hari, bandingkan 3 produk, ekspor CSV |

Mulai dari [`m1_riset/README.md`](m1_riset/README.md). Otomatisasi: [`m1_riset/n8n/PANDUAN_OTOMATIS.md`](m1_riset/n8n/PANDUAN_OTOMATIS.md).

> Repositori ini publik: API key (`.env`) dan data riset (`m1_riset/data/`) sengaja tidak di-commit.
